# MOSS · EREA Consulting

Cuestionario MOSS (adaptabilidad social y habilidad gerencial) y panel privado de reportes de **EREA Consulting**.

- **Encuesta:** https://erea-consulting.github.io/moss/
- **Panel (uso exclusivo del equipo consultor, con token):** https://erea-consulting.github.io/moss/panel.html

Este repositorio contiene solo la interfaz pública: `index.html`, `panel.html` y `assets/`. La clave de calificación, el backend (Google Apps Script) y los datos de los participantes viven en la cuenta de EREA y **no** se publican aquí.

Está prohibida su reproducción total o parcial sin la autorización por escrito de EREA Consulting.
